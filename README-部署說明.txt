Management Exam Prep — iPhone 主畫面版

1. 將這個資料夾的全部檔案上傳到 GitHub repository 的根目錄。
2. 在 GitHub Settings > Pages > Build and deployment 選 Deploy from a branch，Branch 選 main，Folder 選 /(root)，儲存。
3. 等待 GitHub Pages 顯示公開的 HTTPS 網址後，使用 iPhone Safari 開啟該網址。
4. Safari 分享 > 加入主畫面 > 加入。
5. 首次需連線載入；之後 PWA 已快取的頁面可離線使用。

注意：網站連結若公開，其他人可開啟題庫；但 localStorage 練習紀錄留在各自裝置。不同網址／開啟方式的紀錄不會自動同步。請定期使用內建 JSON 匯出備份。
本專案使用老師簡報來源的 65 題練習內容，不是完整學長 PDF 名詞庫。
